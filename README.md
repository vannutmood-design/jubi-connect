# JUBI Connect

Create a mobile communication app called "JUBI" inspired by Discord.

The app should have:

1. User System
- User registration and login
- Username and password
- User profile with avatar, status, and bio
- Online/offline status

2. Community System
- Users can create and join communities (servers)
- Each community has a name, icon, and description
- Community owners can manage members and permissions

3. Chat System
- Text channels inside communities
- Private direct messages between users
- Real-time messaging
- Send images and files
- Message timestamps
- Reply and react to messages

4. Friend System
- Send and accept friend requests
- Friend list
- Block users

5. Interface Design
- Modern dark theme
- Similar layout style to Discord
- Left sidebar for communities
- Channel list
- Main chat area
- User profile section

6. Notifications
- New message notifications
- Friend request notifications

7. Settings
- Account settings
- Privacy settings
- Theme options

Build it as a professional mobile app for Android and iOS with a scalable database and secure user authentication.
